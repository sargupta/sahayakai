The uppercase, tracked saffron label that names a card or section.

**Use** one above a card's content ("Waiting for you", "Say this", "Draft so far") or a website section ("Two people, one rollout").
- `size="app"` (12px, tracked .16em) is the default.
- Use `tight` (.14em) inside composer cards and sheets.
- Use `web` (12px, .18em) on the website.
- Use `tone="muted"` for counts ("3 items queued").

**The consumer provides** the text, written in sentence case; the component uppercases Latin text. It also provides `lang` when the text is not in the page language.

**Rules**
- An eyebrow labels and never instructs: two to four words.
- Indic eyebrows are not uppercased or letter-spaced and render at 12px. Matras and conjuncts break under tracking.
- `saffron-600` is 4.7:1 or better on every app ground except leaf tints, so never put an eyebrow on a leaf tint.
