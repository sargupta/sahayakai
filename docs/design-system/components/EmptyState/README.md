What a screen shows before it has anything in it: VIDYA at rest, a plain title, one line of how it fills, an example.

**Use** for an empty Library, an empty class list, a filter with no posts, or a screen that needs signal (`orbState="offline"`). One per screen, in place of the list it stands for: under the screen header (and any filters), full width between the 20px gutters, above the tab bar.

**The consumer provides**
- `title`: what is missing, said plainly ("Nothing saved yet").
- `body`: one or two lines on how it fills.
- `example`: a labelled sample of what will land here, with real class, board and chapter facts.
- `primary`: the action that fills the screen. `secondary`: a quieter second path.

**Anatomy:** a `surface-glass-strong` card at `radius-card`; a 48px orb, a Bricolage 600 15px title and a 12px `text-body` body centred (max 260px); the example on `surface-inset` with a `border-hairline` edge and a `tight` eyebrow; then a primary and an outline button, 50px, side by side.

**Rules**
- Never blame the teacher or say "No data". Say what will appear and how.
- The example is labelled "Example" so it is never mistaken for saved work.
- Keep board facts board-aware ("CBSE · NCERT Ganita Prakash, Ch 8", "ICSE", "KSEEB"), never NCERT-only.
- The title is an `<h2>` by default and names the section; the orb is decorative.
- Offline: the orb turns grey and the copy says what still works.
- No illustration (decided 26 Oct 2026): one sentence, one action, and the orb where VIDYA can help.
