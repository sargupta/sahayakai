# Logos

**Files**
- `sahayakai-mark-source.png` (900×900): the master raster of the mark (an open book, a caring hand and a four-point spark, in a saffron gradient). App icons, favicons and PWA icons are generated from it.
- `sahayakai-mark.png` (512×512): the mark as used beside the wordmark.
- `sahayakai-app-icon.jpg` (1024×1024): the app-icon lockup (mark plus wordmark on a white rounded tile), for stores and decks.

**Use**
- In UI chrome, set the wordmark "SahayakAI" in Bricolage Grotesque 600 (`ink-900`) beside the mark or a small resting orb.
- On marketing and partner pages, the endorsement "by SARGVISION Intelligence" may sit beside the wordmark in small `ink-500` text.
- Keep clear space of half the mark's height on every side. The minimum size is 24px.
- Place the mark on milk grounds (`milk-50`, `milk-200`) or white, never on saffron or on a photo.

**Don't**
- Redraw, recolour, stretch, outline or add effects.
- Rebuild the mark as a vector by hand.

**Known gap:** no vector master exists. The mark's gradient is brighter than `saffron-500`; that is accepted for the mark only.
