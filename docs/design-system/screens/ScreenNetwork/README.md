Built from the following:
- `ScreenHeader` ("Your network");
- muted `Eyebrow` section headings, with Browse all and Show all as text buttons;
- `GroupRow`s for the teacher's groups, with new-post counts;
- `PersonRow`s with Join for suggested groups (one solid, the rest outline);
- `PersonRow`s with Connect for people you may know (one solid, the rest outline);
- the parked `Orb` and the `TabBar` on Community.

Groups mix boards and states ("Karnataka Teachers", "8 Science · KSEEB", "9 Mathematics · CBSE"). Connect becomes Pending once sent; chat opens only after the other teacher accepts.
