Shared resources: a filterable library of material other teachers have published, two cards across.

Built from the following:
- `ScreenHeader` ("Shared resources", "Material other teachers have published");
- a search `SearchField`;
- filter `Chip`s (All 24, Lessons, Quizzes) and a language filter that opens the `LanguagePicker`;
- `ResourceCard`s in the `.sk-resourcecard-grid`, each with type, class, subject, board and language chips, saves and Save;
- the parked `Orb` and the `TabBar` on Community.

Cards are board-aware: a lesson that follows a board shows it ("CBSE", "KSEEB"). The water cycle is Class 6 Science.
