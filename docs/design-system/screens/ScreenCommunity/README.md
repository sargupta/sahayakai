Community: the feed of what teachers tried, shared, celebrated and asked, with the Daily Briefing on top and VIDYA parked to turn a post into a worksheet.

Built from the following:
- `ScreenHeader` ("Community", "Share, learn and grow with teachers everywhere");
- two `Tile`s, Staff room and Find teachers;
- the `SearchField` post prompt ("What did you do today?");
- `Chip` filters for the post taxonomy: All, Resource, Tried this, Celebrate, Need help;
- `PostCard`s: the automated Daily Briefing with Read more and its board-aware source line, then teachers' posts, with Connect on a teacher the reader does not know yet;
- an `OrbHint` parked bottom-right ("Make a worksheet from this post");
- the `TabBar` on Community.

The Daily Briefing pushes real circulars and names the board that issued them. Messaging opens only after a connection is accepted, so a post offers Connect, never Message.
