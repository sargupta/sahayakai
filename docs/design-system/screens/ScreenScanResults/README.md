Scan results: what the scanner read, how the marks spread, the shared mistake, and the sheets that need the teacher.

Built from the following:
- a `ScreenHeader` with a "Draft marks" `Pill`;
- three `StatTile`s (average, below 5, unreadable);
- a `MarksChart`;
- an indigo `NoticeCard` for the mistake pattern, with a re-teach action;
- a red `Eyebrow` and `ReviewRow`s;
- "Scan more" and "Accept marks" `Button`s beside the resting `Orb`, and the `TabBar` on Library.

Marks stay draft until the teacher accepts them; the stats, the chart and the rows must agree.
