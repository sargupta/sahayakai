1 · Brand & colour palette

The page ground is warm milk with an ink-to-saffron accent. Saffron is the one action colour. Leaf means done or success, indigo means working or info, and red is for errors. Source: src/app/globals.css :root, mapped in tailwind.config.ts.

    11b · VIDYA: the orb is the control

    VidyaPresence (CSS orb, .vidya-* in globals.css), rendered here in every state with the real classes. The app's other renderer, VidyaSphere (WebGL), uses leaf while speaking and is "never red" on error. That conflict is recorded under Inconsistencies.

    The wordmark inside the orb asks for var(--font-bricolage), var(--font-outfit). Neither variable exists, so it falls back to system-ui in the app too. Live CSS
