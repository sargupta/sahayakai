What exists in the codebase, and what this design adds

Already shipped — this design reuses it

  • A school is an organizations/{orgId}; Sampark data lives under sampark_schools/{orgId}/…, so tenant isolation is already the shape of the data.
  • POST /api/sampark/[orgId]/imports — REST pull or two-CSV upload, admin-gated, feature-flagged.
  • A published CRM wire contract (v1) with Zod schemas, REST paging, tombstones, and a flat CSV column spec.
  • Per-record validation with quarantine — one bad row never blocks the school, and every rejection carries a reason and row number.
  • Phone numbers encrypted (AES-GCM) on arrival, peppered hash for matching, only the last four digits anywhere else.
  • SSRF-hardened outbound fetch: https only, public addresses only, no redirects, 15 s timeout.
  • API keys live in Secret Manager by allow-listed name — never in the database.
  • Consent from the provider never overwrites a decision the school or parent made here.
  • School-entered holidays survive every import.
  • A mock school CRM to develop and demo against.

Not there yet — what this design requires

  • There is no school onboarding route at all. /onboarding is the individual teacher's profile setup; a school is provisioned by hand by the Sahayak AI team.
  • No OAuth anywhere — no client registration, no state, no callback route, no token store or refresh.
  • The import contract covers students and guardians only. Classes, sections, teachers, staff and academic years have no import path.
  • No provider registry: no per-provider column mapping, no capability flags, no export instructions.
  • No pre-import dry run — today the only way to see what would happen is to import.
  • No checklist, mapping or confirmation UI. The settings page shows results after the fact.
  • Imports are synchronous inside one request; a large school needs a job with resume.
  • Duplicate detection is by provider id only — no match on admission number or phone.
  • No import audit record beyond the run document, and no idempotency key to make a repeated callback safe.
